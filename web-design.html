  • Agentic development with Claude Code. I direct the agent from brief to deploy: research the client, plan, build, screenshot-test on desktop and phone, fix, ship.
  • Custom Claude skills. My design rules, build process and deployment runbook are packaged as reusable skills, so every build follows the same standards and checks.
  • MCP tool integrations. The agent works directly with Cloudflare, GitHub and other services through the Model Context Protocol and CLIs, with access scoped to each job.
  • Multi-agent orchestration. Parallel sub-agents handle research, builds and code review on larger jobs.
  • Generative AI for media. AI image, video and 3D generation plus AI upscaling for hero visuals when a client's own photos run short.
  • Automated QA. Playwright scripts screenshot every page at real device sizes and exercise the forms before anything goes live.
ben@raleigh:~/projects/ai/bensited$ cat security-baseline.md

The controls I build into client forms and back ends:

  • Bot protection: Cloudflare Turnstile on contact forms, with the token verified server-side.
  • Server-side validation: field allowlists and length caps enforced on the server. Browser limits like maxlength are treated as UX, never as a control.
  • Upload sanitizing: uploaded photos are identified by their magic bytes, not their file name or declared type, then rebuilt server-side. That strips EXIF/GPS location data and any payload appended to the image (polyglot files), and files get server-assigned names.
  • Rate limiting on form endpoints at the edge, using Cloudflare's Workers rate-limit binding.
  • Zero Trust admin: my internal client CRM runs on Cloudflare Workers + D1 behind Cloudflare Access, and was probed from outside to confirm every path is locked.
  • HTTPS everywhere with HSTS, on infrastructure the client owns.
